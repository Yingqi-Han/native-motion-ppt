Native Motion PPT is a skill for editable animated PPTX, shared JSON/Remotion design previews and real desktop playback acceptance.

v1.6.1 prepares a standalone public repository: clearer installation and usage documentation, a source-only package that builds without historical demo outputs, independent archive/install verification, and CI/release workflows. The Python package reads its version from VERSION.

The native exporter, playback capture and motion detector retain the v1.6.0 implementation verified in WPS Linux 11.1.0.11723.XA. Historical evidence covers the five-page scientific example and an independent two-page project, including native bars, actor motion, Morph and automatic advance. See docs/verification.md and showcase/ for exact recording/PPT hashes and scope.

Install the ZIP by extracting it and running `python scripts/install_skill.py --workspace /path/to/project` from the native-motion-ppt folder. Runtime dependencies and player installation are separate.

Windows WPS and Microsoft PowerPoint have not been tested. CI checks source/export/package behavior and does not constitute WPS playback evidence.
