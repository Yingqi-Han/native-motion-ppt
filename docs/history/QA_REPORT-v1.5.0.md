## 检测器故障回归

另制作并真实放映两份原生PPT。故意含60ms短促位移的样本被检出137px帧间跳动，定位到第1页fault-actor、原生shape id 3和录像4.566667秒。修复样本改成2700ms连续闭合路径，重新实播放映后最大帧间变化8px，检查通过。两份PPT、可编辑JSON、录像、校验值和报告随交付保存；故障样本应被拒绝，不能与主项目结果混计。

回归还发现并修正了两类问题：源码与PTS小数边界可能选错一帧，改为由实际PTS选帧号、按帧号解码；已展开柱子的侧边栅格变化可能误报停顿，动作识别改为柱顶变化，并采用中心色带标定顶/底。
