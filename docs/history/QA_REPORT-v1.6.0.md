技术自动检查和视觉审阅分别标注；只有实际查看两份录像/关键帧并附带绑定 SHA 的审阅后，最终验收才通过。当前兼容性只覆盖此 Linux 构建，Windows WPS 和 PowerPoint 没有实机结果。

推荐复核运行是 science-check（同一五页实录的新检查结果）和 generic-record（独立项目的重新实录）。full-wps / checked-wps / generic-wps 保留为父运行或开发中间记录，不把它们的旧结论套到最终交付。检测器修正了渐变色组合轮廓吸收中性背景箭头的问题；最终边界仍取真实像素，未放宽跳变阈值。五页主示例沿用已实播的 1400ms Morph，建议器的 1200ms 只是起点建议，没有冒充新的实播结果。
