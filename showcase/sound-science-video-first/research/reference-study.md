# 在线参考与原创改编

## 选题

声音传过去，空气也会一路跑过去吗？用约一分钟的科普结构讲清局部振动、疏密传播与波长关系，最终成片74秒。

## 在线找到的案例

- University of Salford，Longitudinal Waves： https://salfordacoustics.co.uk/sound-waves/waves-transverse-introduction/longitudinal-waves
- 该页的弹簧视频： https://www.youtube.com/watch?v=ubRlaCCQfDk
- 该页的慢动作弹簧视频： https://www.youtube.com/watch?v=D4Aa8iXl1Oo
- Dan Russell / Penn State，Wave Motion in Mechanical Medium： https://www.acs.psu.edu/drussell/Demos/waves/wavemotion.html
- 事实复核：UCLA Physics，Sound Waves： https://dbauer.physics.ucla.edu/5b/20-sound-waves/

参考里最有效的教学方法是：先选一个标记，观察其往复，再看整片压缩区的移动。我们借鉴这一观察方法，重新编写中文脚本、分镜、图形、镜头放大和220/440Hz听辨，不使用参考视频的画面、配音、原图或逐字翻译。

## 分镜改编

| 主片时间 | 观众要看懂什么 | 本片的原创表达 |
| --- | --- | --- |
| 0—8s | 空气是否随声音远行 | 音箱、阵列与橙色标记提出问题 |
| 8—18s | 局部空气团在往复 | 推近同一个标记，背景降低对比 |
| 18—28s | 疏密变化向前传播 | 移动的青色压缩区与方向箭头 |
| 28—36s | 纵波的两个方向平行 | 往复箭头与传播箭头同向对照 |
| 36—48s | 频率翻倍、波长减半 | 两行粒子场、定格波长尺与220/440Hz纯音 |
| 48—62s | λ=v/f的单位和数量级 | 20°C、343m/s、440Hz、0.78m逐步出现 |
| 62—70s | 回答开头的问题 | 局部往复与向外传播再次对照 |
| 70—74s | 来源和制作方式 | 清楚标注参考和合成旁白 |

## 事实表与表达限制

| 内容 | 核对与制作方式 |
| --- | --- |
| 空气中的声音是纵波 | Salford、Penn State；限定为空气，不泛化为所有弹性介质中的波 |
| 空气团平均运动与传播不同 | 标记点按一维位移公式运动；热运动未画出，点不是被追踪的真实单分子 |
| 压缩对应位移梯度为负 | 代码中pressure_proxy = -cos(phase)，有有限差分单元测试 |
| 20°C空气声速约343m/s | UCLA教学页，使用近似值并标明温度 |
| λ=v/f，440Hz约0.78m | 343/440=.779545...，模型与数值测试核对 |
| 220/440Hz听辨 | 本项目生成纯音，编码后的主片窗口FFT实测220/440Hz |
| 展示速度与真实频率不同 | 所有动态页注明时间与位移放大；两个频率图维持同一视觉传播速度，静止时标“定格测量波长” |

模型是小振幅平面行波的教学示意，忽略衰减、反射及二阶声流。视频是独立原创动画成片；PPT将连续场调整为可讲解的原生定格/往复示意，二者不声称逐帧无损等价。
