# v1.8 实际 WPS 摘录

existing/ 是仓库自制三页现成 PPT 的原版/增强稿、对应真实 WPS 录像、分组计划、实际帧与窄范围检查。4 次新增展开、1 次保留点击和 6 个持续上下文探针通过；仅两页时序改变，其他 50 个包成员原样保留。

boundary/ 是独立点击/自动实录。可测绿色主体通过；文字 Morph 与旋转覆盖仍保留 5 项待检，不是全部通过的项目。诊断页的异常时间与页面上下文另行标记。完整正常回归与未取得到位页面的上下文回归见 [验证说明](../../docs/verification.md)。

这些文件按字节摘录，manifest.json 核对每个成员；缺少部分完整 QA/SDK 依赖，不能直接作为完整运行执行 verify_acceptance.py。完整工程与原始失败记录见 [v1.8.0 Release](https://github.com/Yingqi-Han/native-motion-ppt/releases/tag/v1.8.0) 的 wps-v1.8.0-delivery.zip 和 SHA 文件。

只认证固定国际版 Linux WPS，模拟内容不代表实际业务项目；浏览器 UI、Office 静态参考与 Remotion 视频各有独立来源。旧 v1.6/v1.7 摘录保持不变。安装包排除此目录及所有播放器/私人配置。
