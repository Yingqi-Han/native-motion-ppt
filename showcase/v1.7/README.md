# v1.7 实际 WPS 摘录

product/ 与 progress/ 分别是产品介绍和项目进展示例，画布 1600×900，采集 30fps。原始 MP4、对应双版 PPT、源 JSON、采集证据、最终报告及真实联系表按字节摘录。完整工程在 [v1.7.0 Release](https://github.com/Yingqi-Han/native-motion-ppt/releases/tag/v1.7.0) 的 wps-v1.7.0-delivery.zip，SHA 和具体范围见 [验证说明](../../docs/verification.md) 与 manifest.json。

这些是固定 Linux WPS 的真实 GUI 采集；启动编辑器的提示或黑/暗帧保留，放映阶段独立检查。自动录像的输入证据只含 F5。采集帧率不代表播放器重绘率；设计视频保存在完整工程并标明 Remotion 来源。

这里缺少其他完整 QA 依赖，不能作为完整运行执行 verify_acceptance.py。解压 Release 内相应项目的 acceptance-delivery.zip 后再校验。安装包排除 showcase，私人配置和播放器不在摘录中。历史 v1.6 摘录保持不变。
