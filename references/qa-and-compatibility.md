# 检查与兼容性

## 四类证据分开记录

1. **结构：** ZIP/XML可读、对象ID和时序ID唯一、目标存在、媒体数量、Morph标记。
2. **实际静态页面：** LibreOffice导出PDF，检查所有页面的文本、边界、字体并查看图像。顶层未旋转文本结合PDF字符位置与匹配字体的字形轮廓检查文本框溢出；字体总度量框不等于实际字形边界。
3. **动画导入与预览：** Impress是否保留路径、缩放旋转和逐字动画；Chromium抽取入场、停留、转场帧。
4. **目标桌面放映：** 在用户实际使用的 WPS / Microsoft PowerPoint 版本录屏并放映，确认触发、循环、Morph及排版。记录版本和测试文件校验值，方法见 [实机放映核对](desktop-playback.md)。

前三项不能冒充第四项。即使XML符合规范，播放器也可能忽略某些效果，或以不同方式执行同时变换。设计预演必须标为代码生成；未经实测，目标放映状态保持待复测。

## 必查项目

- 主标题和正文没有漏字、意外换行、遮挡或越界。
- 文本对齐、字距和层级在实际PPT页面里成立。
- 自动版没有意外等待点击；手动版的点击次数符合讲解计划。
- 连续主体的id稳定，Morph没有误配或突兀消失。
- 曲线路径没有跳角，缩放不把主体推到意外位置。
- 动画到位后的画面可读，循环不会干扰内容。
- 全页视频/GIF没有作为动画实现方式。
- 不把预览界面、代码说明或内部检查文字放进正式产品页面。

## 不同播放器

优先以用户指定的桌面播放器和版本为准。Morph需要支持该功能的播放器；旧环境使用文件中的淡切fallback，动画体验会不同。WPS、PowerPoint、Keynote、LibreOffice、网页版的效果和计时需要各自检查，不能依据仓库README笼统宣布兼容。

中文PPT没有嵌入字体；缺字或字体替换时先安装完整字体。预览所带子集只适合该项目使用的字符。

## 回归

tests/test_pipeline.py 检查动画目标和原稿保留；test_quality.py 检查原生多段曲线、固定行距、角色编排、停留时间、字体与升级保护；test_timeline.mjs 还检查曲线切线、循环接缝、Morph 终态与局部时钟。

发布前运行 validate_skill.py，并确保打包内没有node_modules、缓存、绝对路径软链接或临时用户文件。受管理的旧版可 --upgrade；验证旧文件未改动后备份并替换，用户新增文件保留。

竖版与非16:9页面也要检查实际宽高比。check_preview.py 按动作和转场时间自适应采样，--max-samples 默认为每页最多12帧；很复杂的镜头可调高。固定的几个秒数不足以证明较晚的动画正常。

check_motion.py 对指定的顶层主体逐帧测量，包含跨场边界的尺寸与位置。速度峰值随动作目的而变，阈值是诊断工具；查看原始记录和连续视频后再接受动作。浏览器位置连续不等于已验证 PowerPoint 的真实时钟和 Morph 播放。
