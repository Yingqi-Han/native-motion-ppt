# 设计与运动

## 视觉

- 先确立视觉主体。标题、数据、图像或几何可以是主体；不要用许多同等大小的卡片稀释它。
- 标题要能当面说出来。写具体动作、事实和判断，避免“赋能”“智启”“全新范式”等没有信息的宣传词。
- 中文看字形和断句，不机械地照搬英文的大字排版。标题尽量在完整语义处换行；标点随正文。
- 使用明确的字号层级、足够留白和有意的对齐。颜色用于表达重点和状态。
- 用统一的视觉主角串联页面，例如一颗雕塑从大到小、一个框架从空间入口变为标志。不是每页都放同一个装饰。
- 不固定使用“黑底 + 蓝色 + 大字”。示例采用这一组合只是为了展示动作；科研图表、讲义、品牌发布应各自建立视觉语言。

## 时间

可从以下区间起步，再根据实际放映调整：

| 动作 | 起点 |
|---|---|
| 主体入场 | 550–850ms |
| 标签与说明 | 300–500ms |
| 标题内部错开 | 35–80ms/字 |
| 内容块错开 | 100–180ms |
| 普通淡切 | 250–450ms |
| 明确的跨页 Morph | 500–900ms |
| 背景轻缓往返 | 1800–4000ms |

这些是调参起点，不是固定样式。有限动作默认 accel=0.1、decel=0.65，意味着动作起步短、收尾长；适合自然到位。讲清因果时可以线性运动；强调机械节奏时可以短而明确。

主要动画结束后要停留。标题逐字效果总时长是 duration + (字数−1)×letter_delay；不能只算单字时长。

## Morph

同一对象在连续两页保持同一 id；后端将其名称写为 !!id。常见操作是改变位置、尺寸、旋转、颜色和原生几何。

组合内的面片或部件也保留稳定 id，形状数和结构尽量一致。给一个名称完全不同的主体写 Morph 不会自动建立连续关系。

若主体需要离场，可让下一页保留对应对象并移到画布外，再在后续页删除。当前数据检查允许离场几何；必须查看运动路径，避免意外遮挡。

## 空间感

- 前景移动更快，背景更慢；推近时越靠近观众的层缩放越明显。
- 用尺度、遮挡和投影建立空间，不必给所有对象加阴影。
- 三维雕塑可程序化采样曲面、投影、按深度排序，将光照写成每个面的颜色或渐变，再作为原生组合导出。
- 原生组合上的旋转是二维旋转，不意味着真实三维光照随视角更新。
- 示例有240粒子，主视觉以可编辑渐变面片形成反射。渐变应使用每个面的实际边界，避免光照断层。数量由文件大小、编辑流畅度和实际放映决定。

## 图表与学术内容

让动画揭示实验条件、变量、证据和结论的顺序。图表的关键比较应在同一稳定画面可见；不要让读者记住刚刚消失的数据。图例、刻度和正文一般保持稳定。

当前导出器没有自动统计或原生图表接口。Agent 应先完成数据核对，再用原生形状表达或扩展图表后端；不能把虚构的数据写成真实实验结果。

## 设计检查的用法

review 给出具体问题，不给“美观评分”。先处理动画未完成、对象出界等错误，再看低对比度、重叠、停留时间等提示。对比度按声明背景估计，文字覆盖复杂图像时仍需查看实际画面。

同一个内容任务可以采用不同视觉语言。新示例用衬线标题搭配金属主视觉与圆角曲线；竖版示例则强调阅读顺序与连续路径。根据受众选择，避免把演示样例当成所有项目的模板。

## 用户要“惊艳”时，先交付能判断的样片

“能动”只说明效果被播放，不能说明动作有设计。分步淡入适合讲解与保留版式验收；用户明确要求更强的视觉效果时，先从受众与内容中选一段 15—25 秒的视觉主线，做可播放的对照样片，再扩展整套。不要以测试数量或 XML 动画节点数替代审美判断，也不要把“惊艳”写成自动通过的指标。

- 确立一个占据足够画面的主体，让它参与信息表达。主体的聚拢、转向或跨页重组应能说明变化，避免所有元素只从同一方向淡入。
- 把关键动作连起来：准备、变化、到位、停留。主动作期间减少同时抢注意力的标题或背景运动；收尾后再出现数值和结论。
- 跨页复用确实相同的原生对象，先停稳，再用 Morph 改变位置、尺度与方向。不要用两页的代码插值视频冒充原生 Morph。
- 数据位置保留真实含义。图表可以渐进揭示，零基线、坐标与比较框架保持固定；数值标签在对应柱展开后出现。避免越过目标后回弹。
- 查看真实播放器的动作中段，除了检查“出现了”，还要看是否有跳位、双影、遮挡或不合时宜的并行动作。技术证据与用户的视觉评价分别记录。

`examples/cinematic-focus.json` 是一段原创三页运动样片，由 `scripts/create_cinematic_demo.py` 生成：六片扇形重组为六根柱形，再以另一张固定基线图表展示分步生长。所有数值均为模拟数据。它是重做版式与动作的路线，不能声称现成 PPT 的保留增强器会自动生成这些变化；现有增强器的新增动作仍为整体淡入。修改样片后须重新做目标 WPS 实播，不能沿用旧录像作为新文件的结论。

该样片在大号数字上使用与中文一致的 Noto Sans CJK SC 粗体。最初的大号 Space Grotesk 数字在 WPS 与 Office 静态参考间存在字形位置差异；仅在 shell 里确认字体已安装，不能代替查看真实到位画面。图表检查也必须先识别实际页面：相同暖色用于上一页主体时，单靠录制时钟选窗口会混入旧形状。保留原始误报，在新报告中记录实际页面限定，不修改阈值。

`examples/cinematic-focus-zoom.json` 是后续的连续 Morph 版本，也是 `nmp.py new --template cinematic` 的来源。它把同一组六项模拟数据从局部图表重排到全幅：保持柱高与数值的比例，扩大阅读空间，降低其他柱的色彩强度，让最高值成为焦点。这是原生对象的版式变化，不是真实三维镜头。上方参考线缩短以避开大号数字；不要靠不透明标签底色遮住网格，底色在原生 Morph 中可能提前出现并切到移动主体。必须查看转场中段。用 `python scripts/create_cinematic_demo.py --focus-zoom` 重建；原三页文件和历史录像继续保留。


## 漂浮与翻页衔接

金属球的高光已经写进静态面片颜色。将整个组左右旋转会让反射跟着转，看起来像一张贴图；优先用少量曲线漂移和跨页尺度变化。不要把二维组合的旋转包装成真实三维旋转。

环境运动采用自己的节奏。往返运动默认对称加减速；多段曲线在接点检查位置与切线，单向循环检查闭合点。两个不同周期的位移与摇摆容易在换页时落到不同相位。

需要可靠的原生 Morph 时，让共用主体在自动翻页前回到静态布局并停稳。示例的大球以四段三次曲线完成一圈小幅漂移，第一页停稳400ms，第二页停稳520ms。手动放映在停稳后等待点击，位置不会随讲解等待时间改变。

环境动作使用 ambient=true 明确标注；review 的阅读停留忽略这类动作，仍检查它们是否完成。重要图表和论点的变化应保持默认值，不能根据 visual 角色直接推定为环境运动。

浏览器 Morph 从上一场真实动画终态插值到新场初态；上一场的本地时间需扣除它自己的入场转场。连续检查切换前一帧、切换时、切换后一帧，不能只看中点拼图。检查命令见 workflow.md。
